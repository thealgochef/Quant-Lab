Nothing in this document is owner-approved yet — every recommendation is a proposal; real charters carry only the `OwnerDecisionEvidenceRef`s their **actual computation path requires** (`derive_authorization_requirements`, `CONTRACTS_AND_SCHEMAS.md` §3.2) — an unrelated decision is never demanded.

**Classification key** (amended):
- **BLOCKING-BUILD** — must be decided before the corresponding implementation milestone can close.
- **BLOCKING-VERIFICATION** — does **not** block code authoring; **does** block the corresponding release-acceptance gate and every dependent release (Amendment P0-F).
- **BLOCKING-RESEARCH** — implementation proceeds against the proposal; the affected *real research capability* must not launch until the owner ratifies (evidence ref required, scoped to the run's computation path).
- **ENG-AVAIL** — an engineering *availability* decision (what gets built, when): resolved by this plan; owner may override; **implies no research authorization**.
- **PROPOSED-DEFAULT** — a *scientific* value proposed by this plan: stamped `proposed_protocol_default`; **owner ratification required before it carries any research weight**.
- **DEFERRED** — schema supports it; no v1 decision needed.
