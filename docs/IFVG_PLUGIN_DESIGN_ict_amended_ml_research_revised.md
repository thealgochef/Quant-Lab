## 2. PHASE 3 — FSM spec (FOLDED; checkpoint rulings baked into the guards)

Pure reducer: `reduce(state, event, section) → (state′, emissions)` — no I/O, no clocks, no hidden globals; every guard names a §1 param; funnel counters and tier-2 records are *emissions*, never side effects (retained principle from the lost notes doc).

### 2.1 Two layers
- **Context layer (always-on, setup-independent):** the HTF gap registry — detection on 1H/4H closes (C-02 discipline), fill maintenance (**Q-26 final**: 1m granularity, wicks count), retention per `max_active_htf_records` + `htf_retention_rule` (**Q-20 final**: freshest unfilled, fill-filter before cap; reset-bar registration/fill-maintenance guaranteed per §14.2A); parent-TF FVG streams (detection on each enabled parent close — also feeding tier-1 raw counts); the 1m FVG stream.
