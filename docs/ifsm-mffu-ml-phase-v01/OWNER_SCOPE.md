## Explicit phase-01 design defaults
These choices make the accepted plan executable. They are authored experimental conventions, not claims of optimality:
- Two separate regression jobs; entry and exit policies are NOT combined.
- A finite prediction strictly below zero changes the decision; exactly zero stays baseline. Legitimate unavailable model/features -> baseline with a typed reason, never an invented score.
- Ridge alpha 10; constrained CatBoost depth 3 / 200 trees / learning rate .03; full parameters in MODEL_PROTOCOL.json.
- First 80 evaluated dates eligible for the initial fit, two-date separation, then nine contiguous test blocks (eight of 20 dates and one of 11). First scored trading date October 9, 2025.
- Train on a fixed no-account-limit, account-independent shadow of each reference; do not train on account liquidation labels or each ML policy's own selected survivor history.
- For the new continuation action, the first five still exit at their baseline target; an elected close of the remaining five fills only at the first permissible strictly later ordered print, with baseline protection still active.
- Each economic policy starts fresh on the common scored start, carries its own state across folds and pays for replacements. No training-period profits/payouts are credited.
- No tuning from test results; every planned cell stays visible, including statistically unhelpful results.
