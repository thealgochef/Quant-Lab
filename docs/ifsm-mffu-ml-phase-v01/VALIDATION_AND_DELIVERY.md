# Validation, execution evidence and completion
## Required focused tests
Use real functions and public workflow boundaries, not only AST parsing, source-text assertions or mocks that bypass the changed paths. Record test commands, imported source, environment, collection count, pass/fail/skip, return code and source hash. An unavailable dependency is not a pass. Resolve task-local dependencies when possible.

Cover these behaviors:
- Exact inherited 253/10 date scope, correct nine-fold schedule, 171 scored dates, no calendar reconstruction or sealed access.
- Label start/resolution/availability, stop/target/deadline order, next-print continuation close, all leg quantities/fees and R denominator. Synthetic expected cases are in checks/.
- Features unaffected by poisoning FUTURE bars, levels, labels, completed-session statistics, test outcomes or other cells.
- Mid-minute target excludes unfinished candle OHLC; exact namespace/event linkage; nanosecond/microsecond representation without moving the event; nominal report eligibility and early-close/DST boundaries.
- Feature-group isolation: F0 receives no dynamic-allowance/vendor derivative or vendor-missing flag. Missing source values are not invented zero gamma.
- Both fitted preprocessing paths use train data only; fixed domains, imputer/scaler state, model serialization, scored row identity and constant controls.
- Setup/label-interval purge, earlier label availability, no duplicate test predictions, invalid regression folds and baseline fallback. Later folds may use only newly matured earlier labels.
- Genuine negative/zero/positive predictions, nonfinite/unavailable paths, preserved active-family admission: inactive diagnostics cannot discard an eligible pending setup; no repeat same-bar scoring/resurrection.
- Continuation callback keeps first-five target fill, protective stop and account/deadline priorities, charges once, and never fills the remaining five retroactively.
- Changed slot occupancy produces and scores a NEW candidate absent from the old trade list; a saved-trade-ID lookup is insufficient.
- One fresh initial account costs $125; no inactive legacy-five-account fields activated; replacements, pauses, fee equality and floor comparator unchanged.
- Shared pre-score strategy seed with no carried position or economic balance; model activation and retraining never reset accounts. Checkpoint/resume across model update, partial exit, pending voluntary close and payout pause.
- Model-disabled/always-baseline parity against matched controls, scoped reference nonimpact, and no writes to historical source/results.
- Normal UI discovery and result selection, six lenses, accurate product/geometry/action descriptions, point-in-time trade review, export/readback parity.
- Test isolation: import-time monkeypatches/guards are removed after tests and cannot leak into unrelated workflow tests.

A planted causal signal and a future-only poison feature are useful cheap synthetic checks: show the scorer can learn the former and refuses the latter's feature source. They are engineering examples, not research alpha results.

## Review and workload
One cohesive implementation, an independent read-only review of relevant source and resolved science, then targeted fixes/retests. Do not turn every cosmetic change into a full study rerun. A final integrated affected-suite run must cover the DELIVERED source; any full-suite requirement in current repository instructions remains in force, with genuine pre-existing failures identified rather than hidden. Do not rerun a long full suite after documentation-only packaging edits.

Run bounded preflight on cached sources and synthetic fixtures before the expensive label/economic paths. Reuse source derivations and constant models. Let jobs use measured local capacity; fixed single-thread CatBoost fits can be orchestrated without arbitrary GPU/cloud work. Record resource estimates, actual elapsed times, cancellation/resume and recovery facts. No indefinite retry or performance-based search.

## Honest completion
All 24 cell IDs have a terminal record. All valid cells have predictions/metrics and their declared economic policy executed; genuine invalid cells/folds are explicitly represented with baseline fallback/coverage, not silently dropped. A correct study where ML loses is complete. Missing implementation, labels falsely unavailable due to a bug, or a report-only fixed-trade selection is not.

## Deliver BOTH ZIPs together
Use unique run-bound filenames and a separate DELIVERY_RECEIPT.json containing final archive hashes/bytes. Each ZIP has a manifest excluding itself, safe unique paths, relative links, per-file hashes/rows, source/result/report bindings and extracted readback. No references to a second ZIP that was not actually delivered.

### A. Result/UI review ZIP
- README.md with normal UI route, current status, actual source/date scope, and precise review reading order.
- RESULTS.md answering all four study questions, objective and limitations; unfavorable and fallback-only cases retained.
- Resolved cell matrix, folds, feature/label dictionaries, cohort/coverage/censoring reports and source-data identities.
- FULL small feature/label decision datasets for the four reference/job populations, exact availability/event links and label arithmetic (columnar plus reviewable CSV as practical). Do not provide only favorable examples or an incomplete preview.
- Per-fold metrics, constant baselines, every OOS prediction with model/time/row identity, paired feature/model differences, uncertainty and large-continuation retention diagnosis.
- All named operation outcomes and matched-control deltas, actual trades/fills, account journeys, cash/payout ledgers, waiting/activity lens summaries and relevant boundary checks.
- Scored-period start/seed proof and model-coverage/fallback/new-opportunity counts. No source-data duplication across each cell.
- Small genuine Lab captures and index with selection/source version and timestamp; note unavailable real cases.
- Reuse/recovery/protection summaries and all material limitations. No raw tick datasets, credentials or internal scratch logs in the business package.

### B. Source/tests review ZIP
- Resolved approved plan and approval identity, authorizations, task-only source diff AND complete changed source plus minimal dependency closure required by supplied tests (do not omit candles or required modules).
- The actual new label/feature/fold/model/action code and versioned contracts; no replacement implementation only for the reviewer.
- Small test fixtures, exact commands and captured final-source test outputs. Requirements/lock file and honest platform-dependent exclusions.
- Saved Ridge coefficients/imputation/scaler/category state and CatBoost native model artifacts needed to reproduce all fitted predictions, with hashes and fit source/rows/time. If kept in a separate referenced model store due size, include all small fit records and a reproducible verified materialization path; do not claim externally absent binaries were packaged.
- One portable path to check dataset/label arithmetic, replay predictions, and reconcile ledgers without access to raw full-market history; separate real-tape integration tests use verified local registered inputs.
- Exact source/plan/data/fit/result/report identities, original preservation checks, relevant source imports, reviews and resolutions. No unrelated full repository, model cache or new instructions that alter the user's environment.
- Representative full decision traces of a changed action, an unavailable fallback, a newly encountered candidate, and a model-fold transition. Losing examples remain.
- Final delivery receipt may be external to avoid self-hash circularity, but deliver it alongside both ZIPs.

The generated review artifacts must be directly accessible through ordinary My studies. A special environment-variable-only viewer or a promised later report does not meet completion.
