    fix(ml): W3A-READER P0 — zero-touch guard on the vectorized approach-quote pass
    
    process_single_date_stream: the W3a P1 vectorized quote->window pass would
    raise on an empty touches list (empty window arrays; hull min()/max() on an
    empty sequence). The early no-touch return masks it today; guard the block
    with `if touches:` so it is locally a no-op (approach_quotes stays empty —
    the old per-touch loop's natural behavior) regardless of upstream flow.
    
    Zero-touch-day test: real one-hour slice with PDH/PDL seeded absurdly far
    above any stored price — levels exist but cannot be touched; the approach
    pass is configured ON; asserts an empty frame with no error.
