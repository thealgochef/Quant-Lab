    process_single_date_stream quote->approach-window assignment: the per-quote
    pure-Python span scan (O(quotes x touches)) is replaced by chunked numpy
    window membership over epoch-ns (64Ki-event chunks; hull-bounded retention
    preserves the bounded-memory property). The SC feature formulas still consume
    the same Quote objects — single-source intact.
    
    OUTPUT-IDENTITY PROOF (old vs new, full real days, frame.equals — bit-identical
    values incl. NaN placement, dtypes, row order; config tp15/sl15/trap5/iw5/
    aw15/approach-on, no PDH seed):
      2022-02-15: 2 rows;  old 673.9s / new 655.7s  -> IDENTICAL
      2026-02-18: 3 rows;  old 1022.0s / new 1080.9s -> IDENTICAL
        (new ran first on a cold page cache each day; old reran warm)
    
    HONEST TIMING NOTE: near-neutral on the proof days — unseeded days yield few
    touches, so the old quadratic term was small there; per-day cost is dominated
    by the canonical readers two full-day event decodes (pass 1 trades+runtime,
    pass 2 quotes). The new path bounds the quotes x touches term for many-touch
    (seeded) days and is the W-plan precondition for multi-day training; the
    reader cost is SC-owned and out of this windows scope (W3a P2 stop-gate
    measures it).

+            for d in targets
+        ]
+        counts: dict[str, int] = {}

+        peak_day = None
+        done = 0
+        with ProcessPoolExecutor(max_workers=args.workers) as ex:
+            futs = {ex.submit(warm_one_day, t): t[0] for t in tasks}

+                try:
+                    r = fut.result()
+                except Exception as exc:  # broken worker / pool

+                        "rows": -1,
+                        "seconds": 0.0,
+                        "pid": -1,
+                        "status": f"POOL_ERROR:{type(exc).__name__}",
+                        "peak_rss_gb": 0.0,
+                        "err": traceback.format_exc(limit=4),
+                    }
+                done += 1
+                counts[r["status"]] = counts.get(r["status"], 0) + 1
+                if r["peak_rss_gb"] > peak_overall:
+                    peak_overall = r["peak_rss_gb"]
+                    peak_day = r["day"]

+                    f"{ts} day={r['day']} rows={r['rows']} "
+                    f"secs={r['seconds']:.1f} pid={r['pid']} "

+                    f"status={r['status']} [{done}/{len(targets)}]"
+                )

+                logf.write(line + "\n")
+                if r.get("err"):
+                    logf.write(r["err"].rstrip() + "\n")
+                logf.flush()
+
+        wall = (datetime.now(UTC) - start).total_seconds()
+        _n_suggest, math_str = _suggest_workers(peak_overall)
+        summary = (
+            f"# {datetime.now(UTC).isoformat()} DONE wall={wall / 60:.1f}min "
+            f"counts={counts} peak_rss_gb={peak_overall:.2f} (day={peak_day}) "
+            f"| suggested_workers: {math_str}"
+        )
+        print(summary, flush=True)
+        logf.write(summary + "\n")
+        logf.flush()
