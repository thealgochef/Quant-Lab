# Quant-Lab agent start points

Updated: 2026-09-08.

Read [AGENTS.md](AGENTS.md) for repository instructions, verification commands,
research rules and artifact-preservation requirements. That file is the shared
agent guide; this entry point intentionally avoids duplicating changing engine
constants and workflow descriptions.

- [Architecture](ARCHITECTURE.md): ownership and current code paths.
- [Documentation index](docs/README.md): current guides versus historical evidence.
- [Workbench](docs/ML_TRAINING_WORKBENCH.md): ML training and IFVG research UI.
- [Pipeline state](docs/pipeline_state.yaml): implementation summary and limitations.
- [Strategy-Core](../Strategy-Core/README.md): the shared strategy engine.

Verify behavior against executable code and exact saved artifacts. Old plans and
reports describe their recorded revision; they do not establish current runtime
behavior or successful execution of a new study. Preserve local market data,
studies, approvals and audit evidence, including ignored artifacts. New research
launches require the exact-plan authorization described in AGENTS.md.
